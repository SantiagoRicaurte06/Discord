# obsidian (kepano/obsidian-skills)

**Qué hace:** son las skills oficiales para trabajar con Obsidian. Las mantiene Steph Ango (kepano), CEO de Obsidian.

| Skill | Para qué |
|---|---|
| `obsidian-markdown` | Notas con wikilinks, incrustados, callouts y propiedades |
| `obsidian-bases` | Tableros `.base`: vistas de tabla y tarjetas, filtros y fórmulas |
| `json-canvas` | Mapas visuales `.canvas` |
| `obsidian-cli` | Manejar Obsidian desde la terminal (requiere Obsidian abierto) |
| `defuddle` | Sacar una página web limpia en Markdown, gastando menos tokens que WebFetch |

El repo también trae `knap` (plantillas Markdown llenadas desde JSON o CSV). No la instalamos porque por ahora no la necesitamos.
