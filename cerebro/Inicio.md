# 🧠 Cerebro del equipo

Lo que aprendemos de videos e ideas, organizado para convertirlo en **skills** y **proyectos**.

> [!tip] Cómo se alimenta
> Pásale a Claude Code uno o varios links ("procesa estos videos") o una idea suelta. La skill `cerebro` saca la transcripción, escribe las notas aquí y propone skills nuevas. Tú revisas y apruebas.

## Recorrido

```
link o idea ──► Bandeja ──► Videos / Ideas ──► Conceptos (lo que se repite)
                                   │
                                   └──► Skills candidatas ──► (tu OK) ──► catálogo del repo
                                                          └──► skill propia con skill-creator
```

## Carpetas
- **Bandeja**: lo que llega sin ordenar
- **Videos**: una nota por video
- **Ideas**: ideas propias o sacadas de videos
- **Conceptos**: ideas que aparecen en varios videos, explicadas una vez
- **Skills**: skills vistas, evaluadas, adoptadas o creadas
- **Lotes**: cada tanda de links procesada (`enlaces.md`, `referencias-limpias.md`, transcripciones)
- **Tableros**: vistas de Obsidian Bases
